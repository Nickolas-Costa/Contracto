# Contracto

| Automates document generation, PDF/A conversion and digital signature preparation through a modular desktop workflow.

## Overview

Contracto is a desktop application written in Python that automates repetitive document preparation tasks required before digital signature and registration workflows.

Instead of manually editing, renaming and converting multiple files, the application performs these operations automatically while keeping documents organized in a standardized folder structure.

The project follows a modular architecture, making it easy to extend with new document templates and automation modules.

### Why this project?

This project started as an internal workflow automation tool for repetitive document preparation. It evolved into a modular desktop application focused on reducing manual work, improving consistency and preparing documents for digital signature and registration processes.

Its architecture was designed to be reusable and adaptable to different document workflows beyond its original use case.
