# Assets do Contracto

- `templates/` — PDFs oficiais (PPE, 1º Imóvel, ITBI, Isenção, Form Cliente, DAMP, Seguro) usados como modelos, resolvidos via `config/perfis_iniciais.json` (mapa `modelos`) e `utils/resource_path.modelo_configurado()`. Veja "Modelos oficiais embutidos" no README principal.
- `icon.ico` / `icon.png` — Ícone oficial 3D em alta resolução utilizado na janela, na barra de título e na barra de tarefas do Windows.
- `gs/` — Binários e bibliotecas do Ghostscript empacotados para conversão em PDF/A-2b.
