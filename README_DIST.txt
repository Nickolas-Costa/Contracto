  Contracto — Preparação de Documentos Habitacionais
  Guia de Uso Rápido
═══════════════════════════════════════════════════════

COMO USAR:

  1. Abra o arquivo "Contracto.exe" clicando duas vezes.

  2. ETAPA 1 — Preencha os dados dos participantes:
     - Nome completo
     - CPF
     - Endereço completo (apenas o primeiro participante)
     - Data da assinatura no formato DD/MM/AAAA
     - Local da assinatura

  3. Adicione mais participantes se necessário usando o
     botão "+ Adicionar Participante".

  4. Selecione a pasta de saída onde os documentos serão
     salvos (pasta do cliente).

  5. Clique em "GERAR DOCUMENTOS E AVANÇAR".

  6. ETAPA 2 — Selecione os documentos adicionais:
     - Contrato (.rtf ou .pdf)
     - Planilha de Evolução
     - Protocolo da Planilha
     - Aviso de Crédito
     - Origem de Recursos

  7. Clique em "FINALIZAR PROCESSO" para converter tudo
     para PDF/A e organizar na estrutura de pastas.


OBSERVAÇÕES:

  • Arquivos .RTF são aceitos e convertidos automaticamente.
    (Requer Microsoft Word instalado no computador.)

  • Os documentos serão organizados na estrutura:
    PASTA DO CLIENTE/
    └── PDF-A/
        └── ASSINADOS/
            └── REGISTRADOS/

  • O CPF é validado automaticamente.

  • Os nomes dos arquivos seguem o padrão:
    PRIMEIRO IMOVEL - NOME.pdf
    PPE - NOME.pdf
    CONTRATO NOME1 E NOME2.pdf

  • Em caso de erro, verifique o arquivo "app.log" na
    mesma pasta do executável.


REQUISITOS DO COMPUTADOR:

  • Windows 10 ou superior
  • Microsoft Word (apenas se for usar arquivos .RTF)
  • NÃO é necessário instalar Python
  • NÃO é necessário instalar Ghostscript (já embutido)
