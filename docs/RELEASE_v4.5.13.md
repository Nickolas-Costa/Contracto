# Contracto 4.5.13

Manutenção da série 4.5.x, com as correções de interface acumuladas desde a 4.5.12.

## Formulários

- Os 7 campos SIM/NÃO do DAMP passaram de lista suspensa para caixa de seleção, mantendo os valores esperados pelas regras do formulário.
- Caixa de seleção aceita par de opções configurável (marcado/desmarcado).

## Interface

- Fluxo de formulários e paginação aprimorados, sem rastros visuais na troca de perfil.
- Edição de campos restaurada e alertas sem lista de erros corrigidos.
- Toasts com tipo informativo, duração configurável e exemplar único por vez.

## Instalação

Baixe `Contracto_v4.5.13.zip` e o `.sha256.txt` abaixo, extraia e execute.
Não requer Python instalado. Requer Windows 10/11 (64-bit) e Microsoft Word
para conversão de arquivos RTF.
