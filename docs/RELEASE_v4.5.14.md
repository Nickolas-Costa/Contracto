# Contracto 4.5.14

Manutenção com identidade visual própria e avisos corrigidos.

## Design

- `docs/DESIGN.md`: linguagem sóbria, leve e focada, com as ondas na cor de destaque como assinatura, tokens CSS e checklist por tela.
- Direção definida para a versão web (Fluent 2 + Carbon + shadcn) com prompt pronto para o agente de design.

## Interface

- Toast contido na janela em qualquer escala de tela, com dispensa por teclado.
- Boas-vindas abrem somente com a janela visível e texto refeito.

## Instalação

Baixe `Contracto_v4.5.14.zip` e o `.sha256.txt` abaixo, extraia e execute.
Não requer Python instalado. Requer Windows 10/11 (64-bit) e Microsoft Word
para conversão de arquivos RTF.
