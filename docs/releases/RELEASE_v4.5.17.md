# Contracto 4.5.17

Interface web sobre a API local e participante modular.

## Interface web

- Etapa 1 e 2 sobre a API local: catálogo, composição, participantes, destino, geração, anexos, processamento, visualizador e Config com tema (shell `--ui` para testes).
- Revisão visual: scroll estilizado, logo, stepper em 4 etapas, Config no topo, selecionar-todos, resumo com links, fundo modular e modais com faixa e X.

## Núcleo

- Participante modular dirigido pelo perfil, sem quebrar chamadas existentes.
- Bateria adversarial da API sem vulnerabilidade real.

## Instalação

Baixe `Contracto_v4.5.17.zip` e o `.sha256.txt` abaixo, extraia e execute.
Não requer Python instalado. Requer Windows 10/11 (64-bit) e Microsoft Word
para conversão de arquivos RTF.
